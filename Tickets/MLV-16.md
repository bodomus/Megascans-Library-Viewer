# MLV-16 — Глобальный поиск по библиотеке ScanVault

Источник: https://bodomus.youtrack.cloud/issue/MLV-16/Globalnyj-poisk-po-biblioteke-ScanVault

## Цель

Добавить отдельный глобальный поиск по всей последней успешно просканированной библиотеке. Поиск не должен зависеть от выбранной папки, текущей категории или локальных фильтров и не должен повторно читать файловую систему.

## Требования

- Отдельное заметное поле Global Search с запуском по Enter, кнопке и с безопасным debounce; кнопка очистки возвращает обычный режим.
- Поиск по имени, Asset ID, типу, пути, именам индексированных файлов, категориям, тегам, biome/region и вариантам.
- Маски: `*` — любое количество символов, `_` — ровно один символ. Остальные символы, включая regex-метасимволы, трактуются буквально. Без масок выполняется регистронезависимый поиск подстроки.
- Результаты содержат количество, тип, расположение и причину совпадения; доступны фильтры Mesh, Material, Texture, Atlas/Billboard, Other.
- Show in Library выбирает папку и ассет; существующие действия карточки остаются доступны.
- Пустой запрос завершает глобальный режим; отсутствие результатов и ещё не просканированная библиотека показываются явно.
- Поиск не блокирует UI; новый запрос отменяет или делает неактуальным старый. Ошибка показывается рядом с полем и журналируется.
- Не менять формат индекса без необходимости, не ломать навигацию, локальные фильтры, сортировку, карточки и историю.
- Логику масок покрыть unit-тестами; глобальность, поля, типы, очистку, stale-result и ошибку — ViewModel-тестами.

## Критерии приёмки

- Глобальный поиск работает по всей загруженной индексированной библиотеке независимо от дерева.
- Поддержаны `*`, `_`, буквальная обработка regex-символов и регистронезависимость.
- Видны причина совпадения, расположение, количество и фильтр типа.
- Очистка восстанавливает прежнее дерево/сортировку/локальные фильтры.
- Поиск отменяемый, не запускает сканирование и не закрывает приложение при ошибке.
- Новые и существующие тесты проходят.
- После реализации задокументировать архитектуру, фактические поля поиска, тесты и статус Find related.
