# Review MLV-6 — Diagnostics and index compatibility

## Результат

MLV-6 выполнен. В ScanVault добавлено компактное окно **About / Diagnostics** со стабильным текстовым отчетом и командой **Copy diagnostics**. Совместимость SQLite теперь определяется явным состоянием до любых записей. Индексы более новой версии и поврежденные индексы сохраняются без изменения, а Rescan для них блокируется.

## Что сделано

- Добавлены состояния `Compatible`, `RequiresMigration`, `RequiresRescan`, `NewerVersionUnsupported`, `Missing`, `Corrupted`.
- Проверка существующей SQLite выполняется read-only до WAL и других записывающих операций.
- Сохранена поддерживаемая транзакционная миграция schema v1→v2.
- Устаревшая normalization version остается читаемой и требует явного Rescan.
- Сведения об успешном скане сохраняются в одной транзакции с каталогом и читаются после перезапуска; старый JSON поддерживается.
- Diagnostics показывает версии приложения/сборки/схемы/нормализации, runtime/OS/architecture, пути, библиотеку, счетчик, состояние индекса и сведения о скане.
- Формат отчета имеет фиксированный порядок, единое значение `Unavailable`, не перечисляет окружение и не содержит stack trace.
- Ошибка системного clipboard не закрывает окно и выводит понятный статус.
- Добавлены краткие startup-сообщения и блокировка небезопасного Rescan.
- Обновлены README, архитектура, формат индекса и отдельная инструкция `Docs/diagnostics.md`.

## Безопасность данных

- Индекс новой версии не понижается и не открывается на запись.
- Поврежденный индекс не удаляется, не переименовывается и не заменяется автоматически.
- Перед записью совместимость проверяется повторно.
- Отмена/ошибка замены не удаляет прежние строки индекса.
- Восстановление для новой/поврежденной базы документировано как ручное действие после резервной копии.
